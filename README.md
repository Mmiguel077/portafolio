# 🚀 Portafolio Personal - Miguel

Sitio web portafolio con diseño minimalista en modo oscuro, construido con HTML semántico, CSS modular y microinteracciones fluidas.

---

## 🛠️ Tecnologías
- **HTML5**: Estructura semántica (`<section>`, `<form>`, `<label>`, `<footer>`).
- **CSS3**: Diseño modular, Flexbox, variables/paleta de colores coherente y transiciones fluidas (`0.3s ease`).
- **SVG en línea**: Iconos vectoriales nativos para canales de contacto.
- **Formspree**: Procesamiento de formulario de contacto sin backend propio.

---

## ✨ Características
- **Modo oscuro nativo**: Paleta de fondo oscuro (`#121214`) con acentos en esmeralda (`#00b37e`).
- **Diseño responsivo**: Adaptable a escritorio y dispositivos móviles con apilamiento fluido.
- **Canales de contacto flotantes**: Botones fijos (`position: fixed`) de WhatsApp y Telegram.
- **Formulario funcional**: Validación semántica de correo (`type="email"`), campos requeridos y entrega directa a bandeja mediante Formspree.
